## 1. 目标与本轮授权

以下载器为核心，将漫画源变成可替换插件。用户像在 Tachiyomi 中浏览漫画源一样找到作品、看简介和目录、添加订阅；程序专注离线下载和 CBZ，不提供在线阅读。嬉皮漫画为当前优先候选。

用户本轮原话：“既然这样你就读取工作流插件并评估项目难度和开启对话串把，我对当前的要求是有明确的对话串、以及s0项目文档”。

本轮允许读取、评估、编写文档及建立职责明确的对话。新架构开发、数据迁移、提交推送、镜像发布和 NAS 操作尚未授权。此前 v0.1.7 已结束，旧发布授权不自动延伸为新架构发布授权。

## 2. 用户流程与建议首版

漫画源浏览/搜索 → 详情与目录 → 选择范围 → 添加订阅 → 手动/定时入队 → 查看状态 → 生成 CBZ；失败后补下载。

建议范围（待用户 S0 确认）：
- 源插件采用受控、随应用打包的 Python 模块，声明稳定 source_id、插件版本、核心接口版本和能力。
- 核心统一队列、订阅、逐章完成记录、网络、限流、代理、图片保存、CBZ、停止与重试。
- 嬉皮作为首版唯一实际启用的新源。旧五个源数据完整保留并默认不自动运行；保留兼容导入/展示，不要求五个旧适配同时改造成可用插件，不以解除 210 为退出条件。
- 用离线测试源验证核心不依赖任何真实源的专用字段；测试源不展示给用户。
- 复用封面订阅、范围选择、任务页、自动检查；源不支持的筛选/账号能力不展示虚假选项。
- 保持单进程、串行下载与当前停止语义。
- 保持 Docker 仓库、8000 端口及 /data、/downloads、/cbz 映射。

首版不包含：APK 插件直接运行、第三方插件市场、在线安装/热更新、在线阅读、自动跨源合并进度、自动批量迁移订阅、任意不连续章节选择、多用户、分布式下载、多 worker 或并行大批量下载。

内置 Python 插件与核心同进程，不是安全沙箱；外部插件安装的信任和隔离须后续单独设计。

## 5. 责任边界与 S1 契约议题

| 核心负责 | 插件负责 |
| --- | --- |
| 订阅、范围、稳定身份、完成记录 | 浏览、搜索、支持的筛选、详情和目录 |
| 队列、停止、重试、任务历史 | 有序图片清单、必要解码和图片处理声明 |
| 网络执行、代理、限流、保存与打包 | 账号会话、线路、Referer 等访问上下文 |
| 通用状态与成功条件 | 将源错误转换为原因明确、可重试性明确的错误 |

插件不独立写完成记录、删除临时文件或打包。网络接口须允许必要的源逻辑，不能为了统一而每张图重登或向 CDN 发送账号 Token。

S1 必须明确：
1. Source/Comic/Chapter/Image 最小字段、可选能力、分页和完整目录证明。
2. source_id + comic_id + chapter_id 身份，分组、同名章节、重排、删除和修订。
3. 会话生命周期、请求头作用范围、限流、Retry-After、错误分类和停止。
4. 图片地址过期、线路或图片顺序变化时的刷新与安全补下载规则。
5. 旧 JSON 的备份、幂等导入、版本检测和回退；未知历史保持未知。
6. 同名作品的输出目录和 CBZ 冲突，现有路径的兼容策略。
7. 插件禁用、失败或版本不兼容时，任务有解释而不崩溃或假报无更新。
8. CBZ 文件提交、完成记录提交、临时图片清理之间的恢复协议：每个边界崩溃或写入失败均可判定状态，不重复计数、不误推进、不丢失可恢复依据。

旧数据保留范围包含 copymanga、terra_historicus、antbyw、ganganonline、bilibili 以及未知源的记录、未知字段、任务历史、源设置和既有下载文件；无法导入的内容保留原始备份并明确提示，不能过滤后静默丢弃。保留数据不等于承诺这些源的实际下载可用。S1 的兼容清单须覆盖配置、订阅、任务历史、CBZ、临时图片之间的引用；旧镜像回退使用兼容快照，不能直接写新格式数据。

S0 不预先固定所有函数签名或存储技术；这些是 S1 的交付。

## 8. 首版验收重点

- 换源不修改核心队列或保存逻辑；测试源证明不依赖站点专用字段。
- 真实浏览到 CBZ 闭环；目录或图片清单成功不能替代下载成功。
- 图片失败、清单不完整、打包或记录写入失败都不虚报完成。
- 专门验证“CBZ 已落盘、完成记录尚未提交”和“记录已提交、临时文件尚未清理”的故障/重启窗口；能校验文件并恢复，不能因临时图片已删而失去唯一恢复依据。
- 对“记录声称完成但 CBZ 缺失/损坏”也有校验与恢复路径；不能只凭文件名认领同名旧产物，不无条件覆盖。S1 给正反样例，S2 用故障夹具验证。
- 跨源同名作品、同名章节及不同分组不混淆。
- 只在身份与顺序可证明一致时复用临时图片，否则隔离，保留旧临时文件。
- 旧数据先备份，历史未知不造假，不按名称自动跨源迁移。
- 取消订阅不删文件，停止不推进未完成章节，中断可恢复。
- Token 不发给 CDN，错误和日志不泄露密码、会话或代理认证。
- 不兼容的新旧数据版本必须明确阻止并提供回退，不静默覆盖。
