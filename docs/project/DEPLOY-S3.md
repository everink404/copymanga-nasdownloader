# S3 可部署版 v0.2.0-rc.1

镜像：`montequilla/copymanga-nasdownloader:v0.2.0-rc.1`（linux/amd64）。使用仓库 `compose.s3.yaml`。本版是独立的新下载核心和界面，暂不覆盖旧版 `latest`。

## 飞牛部署

Docker → 镜像 → 拉取镜像，填写上述完整地址。创建容器时映射：

| 项目 | 主机 | 容器 |
| --- | --- | --- |
| 端口 | 18003 | 8000/TCP |
| 配置与任务 | 自选持久目录/data | /data |
| 下载暂存 | 自选持久目录/downloads | /downloads |
| 完成漫画 | 自选持久目录/cbz | /cbz |

三个目录均读写。首次部署使用独立目录，不与正在运行的旧版共用。已经运行 S3 的容器可以保留三个原映射，换镜像后重建容器。不要删除持久目录或卷。打开 `http://NAS地址:18003`。

在“源设置”中填写所需源的代理（含认证时按代理要求填写）；保存后不回显。浏览漫画，进入目录，选择全部、仅新增或指定章节起点，先预览再确认订阅。“下载任务”查看进度和错误，“我的订阅”管理暂停/恢复和检查周期。无在线阅读功能。

## 本次修复与边界

拷贝 API 新协议对应 Copy20 1.4.85：请求头按 API 主机发送；目录采用 limit=100 和 _update=true；新安装默认 api.copy4000.com。已有配置不自动换地址或转移账号，换 API 地址会清除旧凭据。可在源设置选择旧协议用于排查。未取得目录不订阅；图片数与源声明不符不下载、不记完成。

2026-11-01，NAS 相同代理下，旧协议/API 域名与新版协议/API 域名的两次匿名详情请求均返回 HTTP 210。本版**不宣称拷贝漫画可正常订阅下载**，不承诺解除站点限制。嬉皮已完成真实整章下载，最终镜像须再次校验已有 CBZ 和重建后的状态。正式旧容器不自动升级。

源诊断仅返回阶段、错误代码、HTTP 状态和分组数量，不返回账号、代理、Token、Cookie 或响应正文。不要把本服务直接暴露到互联网。
