1. 本对话是唯一用户决策入口，负责 S0 汇总、范围和状态；后续获准后兼任开发、自检与整合。
2. 架构规划对话提供 S0 范围、契约议题、迁移和工作量意见；S0 报告已交付；本批 S1 由入口设计，未再派发规划任务。
3. 独立评审对话检查范围内契约、证据、风险、退出条件和授权；S0 报告不能替代新 S1 评审，其结论不替代实现或用户验收。

不为每个源或前后端另拆工作线。共同契约或迁移有实际依赖时，由入口组织一次检查。

应用登记的项目列表没有本仓库，因此本轮新建的是本地规划文档任务，初始消息给出源码和文档绝对路径；不选择其他项目，也不开展仓库开发。正式开发仍在当前源码工作区。以后若需要单独的仓库开发对话，先登记正确目录。

## 工作规则

按已授权范围完成必要规划、实施、自检、交付；独立检查和设备确认仅在改动需要时进行，不机械地把每一步设为放行门。
常规技术细化、范围内返修自主完成；产品取舍、新增范围和阶段放行集中交本入口。
规划、自检、独立评审、用户验收、NAS 验证、发布分别登记并绑定版本。未知写待验证，历史通过带日期，不互相替代。

S0 的创建任务授权已完成。2026-10-18 用户新增限定授权 D-006：本入口可向现有独立评审对话下发 DESIGN-S1-20261018 的评审与必要文档返修，入口只读回收报告；不授权反向发送、其他对话互发或自动化。后续不在本批范围的任务仍需对应授权。
新对话只写自己的规划/评审报告，不改共享 S0、STATUS 或产品代码；共同文档由入口维护。
本轮不开发、不迁移、不提交推送、不发布、不操作 NAS；后续用户明确启动相应阶段即可推进。

## 报告最小字段

日常只写镜像版本、本次变化、怎么试及结果、更新/必要回退。提交与镜像指纹自动记录，不要求用户核验；无须另建编号报告、签字表或额外状态文件。重要问题保留必要证据，历史规划/评审报告仍可查，不覆盖原结论。
