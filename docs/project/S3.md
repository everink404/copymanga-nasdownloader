# S3：漫画源与订阅界面候选版

范围：嬉皮漫画、拷贝漫画作为内置源，共用 S2 下载核心；提供浏览、搜索、分页、排序/可用筛选、简介封面和分组目录，不提供在线阅读。

本次实现：订阅封面卡片，全部/仅新增/指定起点，预览完整目录后确认；运行、暂停、取消恢复、修改范围、定时检查（默认 120 小时）；任务进度、错误、重试、CBZ 下载。两个源分别保存 HTTPS 地址和代理，拷贝支持账号配置；密码/Token/代理不回显。封面通过所选源代理获取并缓存。

候选镜像：`montequilla/copymanga-nasdownloader:s3-preview`，linux/amd64；固定标签 `s3-ce2644c15a4dccf6cf29a356d32a7b044c6b883a`，代码提交 `ce2644c`，分支 `feature/source-ui-s3`。只发布候选，不同步 `latest`。
根指纹：`sha256:b05c7c33f97300645db021b28e32ed6771a4cac352c6451fc082af1d9dea6c38`。
使用 `compose.s3.yaml` 创建独立容器，打开 `http://NAS地址:18003`。三个卷独立；不要复用正在运行的旧容器目录。停止 S3 即可回到旧容器，文件保留。常规 Docker 端口、`/data`、`/downloads`、`/cbz` 映射保持一致。

拷贝兼容原环境变量 `CMNAS_API_URL`、`CMNAS_CM_WEB_URL`、`CMNAS_CM_USERNAME`、`CMNAS_CM_PASSWORD`、`CMNAS_CM_TOKEN`、`CMNAS_CM_PROXY`、`CMNAS_CM_RATE_LIMIT_PER_MINUTE`；源设置保存后优先使用已保存配置。更换 API 主机会清除旧凭据，避免自动发送到新主机。

本地 27 项核心/源检查与 53 项旧功能回归通过；[最终提交 CI](https://github.com/everink404/copymanga-nasdownloader/actions/runs/41226287806)的构建、样例下载及容器重启通过。27 项包含同站会话保留、CDN 不携带网站凭据、跳转身份检查、只导入代理和清除后不复活。

飞牛实例 `cmnas-s3-test`：`http://192.168.31.8:18003`；三个目录在 `/vol1/1000/tset/cmnas-s3-20261101/` 下。按用户授权仅复用了旧代理；账号、密码、Token 为空，旧文件未修改，一次性读取挂载已移除。正式容器及其目录保留。

本机/NAS 直连存在网络差异；本次 NAS 实章经已保存代理完成。支持图片线路一/二切换，不承诺任意网络直连可用。
嬉皮只支持热门/更新排序，不伪造分类或状态筛选；源站模糊搜索可能返回相关或不相关作品。拷贝支持状态筛选，搜索时不能同时用状态筛选。
拷贝仍受到本次匿名访问条件下的目录限制。只在取得完整目录/图片清单后允许订阅或下载；不宣称绕过 210，也不把未执行的账号登录或拷贝实章下载写成通过。S3 候选已交付，完整双源可用性仍有这项外部缺口。
源协议参考公开的 [HipmhFast](https://github.com/keiyoushi/extensions-source/tree/master/src/zh/hipmhfast)；拷贝延续本仓库既有 API/官网解析。没有运行 Android 插件 APK。

本地复核：`python -m pip install -r requirements-s3.txt`，`python -m unittest discover -s tests_core -v`。
