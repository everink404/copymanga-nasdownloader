# S3：漫画源与订阅界面候选版

范围：嬉皮漫画、拷贝漫画作为内置源，共用 S2 下载核心；提供浏览、搜索、分页、排序/可用筛选、简介封面和分组目录，不提供在线阅读。

本次实现：订阅封面卡片，全部/仅新增/指定起点，预览完整目录后确认；运行、暂停、取消恢复、修改范围、定时检查（默认 120 小时）；任务进度、错误、重试、CBZ 下载。两个源分别保存 HTTPS 地址、代理和账号，保存后的密码/Token/代理不回显。

候选镜像：`montequilla/copymanga-nasdownloader:s3-preview`，linux/amd64；固定镜像为 `s3-<代码提交>`。只发布候选，不同步 `latest`。
使用 `compose.s3.yaml` 创建独立容器，打开 `http://NAS地址:18003`。三个卷独立；不要复用正在运行的旧容器目录。停止 S3 即可回到旧容器，文件保留。常规 Docker 端口、`/data`、`/downloads`、`/cbz` 映射保持一致。

拷贝兼容原环境变量 `CMNAS_API_URL`、`CMNAS_CM_WEB_URL`、`CMNAS_CM_USERNAME`、`CMNAS_CM_PASSWORD`、`CMNAS_CM_TOKEN`、`CMNAS_CM_PROXY`、`CMNAS_CM_RATE_LIMIT_PER_MINUTE`；源设置保存后优先使用已保存配置。更换 API 主机会清除旧凭据，避免自动发送到新主机。

## 验证与已知边界

本地 23 项核心/源测试通过。真实源与 NAS 整章验证进行中，尚不将其写为通过。
嬉皮公开列表、实际名称搜索、简介、820 章目录首页和 17 页图片清单可取得；本机直连第一图片线路失败，需在 NAS 检查。支持在线路一/二之间切换。
嬉皮只支持热门/更新排序，不伪造分类或状态筛选；源站模糊搜索可能返回相关或不相关作品。拷贝支持状态筛选，搜索时不能同时用状态筛选。
拷贝仍可能受到 210 或网络限制。官网回退只有取得完整目录/图片清单才允许订阅或下载，不能解除站点限制；失败不推进完成记录。
源协议参考公开的 [HipmhFast](https://github.com/keiyoushi/extensions-source/tree/master/src/zh/hipmhfast)；拷贝延续本仓库既有 API/官网解析。没有运行 Android 插件 APK。

本地复核：`python -m pip install -r requirements-s3.txt`，`python -m unittest discover -s tests_core -v`。
