# CopyManga 漫画源浏览：更新规划

状态：首版已实现并完成离线测试；真实漫画详情和目录接口需在未受 CopyManga 限制的网络环境中验证。本文保留设计范围与验收标准。

## 目标与使用流程

在现有 WebUI 增加「漫画源」入口，让用户像使用 Mihon 的漫画源一样，直接浏览 CopyManga 的公开漫画信息。无需先导入账号收藏，也无需手填 `path_word` 或 `group_word`。

1. 打开「漫画源」，浏览漫画列表，或输入名称搜索；结果按页加载，显示封面、标题及接口实际提供的更新信息。
2. 打开漫画详情，查看封面、作者、简介、状态、更新信息和可用分组；切换分组后查看该组的章节目录。
3. 点击「加入订阅」，选择下载范围，确认漫画名称和分组。保存后返回「我的订阅」，后续仍由现有手动运行或定时任务下载 CBZ。

浏览页只展示元数据和章节目录；不请求章节图片，不提供在线阅读。浏览与账号收藏无关。公开接口若允许匿名访问，则浏览不要求登录；需要鉴权时复用现有 CopyManga 账号配置，并给出明确的登录失败提示。

## 首版范围

| 功能 | 首版行为 |
| --- | --- |
| 列表与搜索 | 支持分页、加载状态、空结果和重试；先验证可用的公开列表/搜索接口，再确定首页的“最近更新”等排序是否可提供。 |
| 漫画详情 | 展示接口返回的元数据和封面；缺失字段不阻断页面。 |
| 分组与目录 | 展示接口返回的可用分组及各组章节，按需分页加载；不只读取前 500 章。 |
| 加入订阅 | 自动填入现有 `updater.json` 所需字段，并以 `path_word + group_word` 判断是否已订阅；已订阅时进入现有订阅管理，不重复新增。 |
| 下载范围 | 用户可选「从头下载」「只下载以后更新」「从指定章节开始」。默认建议在确认页让用户明确选择，不静默开启大量历史下载。 |
| 现有功能 | 保留手动添加、高级编辑、定时任务、下载目录和 CBZ 行为；不迁移旧订阅。 |

「从指定章节开始」包含所选章节。当前下载器的 `latest_chapter` 表示**已经完成的最后一章**，实际下载会从它的后一章开始。因此实现时应把所选章节的前一章写成起点；若选择第一章，则留空。选择「只下载以后更新」时，把当前目录末章记为起点。所选分组的章节顺序必须先核对接口的 `index`，不能简单按展示顺序或名称推断。写入前应让用户看到首个待下载章节；目录为空或加载失败时禁止保存这类范围选项。

现有更新器按章节**名称**查找 `latest_chapter`。若同一分组出现同名章节，起点可能歧义；首版会拒绝从页面添加这种分组，避免写入不可靠游标。后续若支持它，应以章节 UUID 保存更稳定的游标，同时兼容旧记录。目录变化、章节删除或重排时也要避免误判为“全部已下载”。

## 实施步骤

1. **确认接口。** 在既有 `CMNAS_API_URL` 和代理设置下，验证列表、搜索、详情、分组、章节分页接口及字段；确认匿名/登录差异和封面地址。CopyManga 接口可能变化，验证结果决定首页可用的浏览排序与筛选项。
2. **新增只读后端接口。** 由服务器请求 CopyManga，统一返回前端需要的漫画、分组和章节字段；所有 CopyManga API 请求继续使用全局限流与 429 重试。对超时、210、429、鉴权失败、无效数据分别返回可理解的错误，避免浏览失败影响下载任务。
3. **新增 WebUI 页面。** 在现有导航加入「漫画源」，实现列表/搜索、详情、分组和章节目录；适配手机和 NAS 浏览器。封面加载失败时显示占位图，不影响文字信息。
4. **接入订阅。** 复用现有订阅配置格式和下载流程，由服务端校验身份、分组、章节起点和重复项后写入；保留已有其他漫画源的记录。若继续使用整份 `/api/config` 保存，须处理并发修改覆盖问题。
5. **验证与发布。** 覆盖空结果、接口失败、不同分组、重复订阅、三种下载范围、超长目录和旧订阅兼容；完成后更新 README 的使用说明，构建并验证新镜像，再给出 NAS 更新步骤。

## 验收标准

- 用户不需要查找 `path_word`、导入收藏或手改 JSON，就能从漫画源找到一部漫画、查看目录并加入订阅。
- 「从头下载」「只下载以后更新」「从指定章节开始」保存后，下一次任务的待下载章节与确认页预览一致；浏览或保存操作本身不自动开始下载。
- 重复添加同一漫画的同一分组不会产生重复记录；不同分组可以分别订阅。
- 浏览失败会给出可重试提示，不会使 WebUI 或既有定时下载退出；已有订阅和数据卷无需迁移。
- 章节目录即使超过当前单次请求的 500 章限制，也能完整浏览并正确选择起点。

## 暂不纳入

账号收藏导入或同步、在线阅读、图片预览、自动推荐、按任意不连续章节批量下载。这些能力与本次“浏览漫画源并订阅下载”的目标不同，首版不依赖它们。

## 现场验证记录

开发环境可以取得 CopyManga 排行榜响应；漫画详情和章节目录请求返回 HTTP 210 限制提示，因此这两种真实响应结构及封面在飞牛 NAS 浏览器中的加载情况仍需现场验证。遇到 210 时首版显示错误与重试入口，不会把请求失败当作空目录，也不会写入订阅。离线测试覆盖了模拟详情、分组、超过 500 章目录、三种下载范围及重复订阅。
