# 订阅与下载任务界面

WebUI 仅展示拷贝漫画，导航为漫画源、我的订阅、下载任务、设置。原有其他源的后台实现和配置数据保留；WebUI 的手动运行和自动检查只处理拷贝漫画订阅。

## 我的订阅

- 用封面卡片展示漫画，可按名称搜索，按下载中、等待中、失败或中断、暂停订阅筛选。
- 新订阅保存封面。旧订阅会按顺序尝试补取封面，取得失败时使用占位图，不影响管理订阅。
- 点击卡片查看简介、订阅分组、章节目录，目录支持每页 100 章翻页。
- 可单独运行一部订阅，查看任务，修改下载范围，暂停自动检查或取消订阅。
- 修改范围支持从头、只下载后续更新、指定章节开始；保存会重设进度起点，已下载文件保留。
- 暂停订阅取消尚未开始的排队任务，当前章节下载任务继续；后续不会自动检查。取消订阅不删除图片或 CBZ。
- 下载中或排队中的订阅不能修改范围或取消，须先停止任务并等待退出。

旧订阅的最后完成章节也可能是添加订阅时跳过的位置，不能据此推算下载数量。旧数量显示为未统计，新完成章节逐章保存到 downloaded_chapters；重下同名章节不重复计数。目录标记区分实际记录的已下载、已处理但可能跳过、待检查和未核实。不会扫描旧文件补造历史记录。

## 下载任务

- 手动运行、单部运行、定时检查使用同一个串行队列，同一漫画分组的活动任务不会重复入队。
- 展示漫画、阶段、章节、本次完成章节数、当前图片进度、本次传输量、最近一张图片的平均下载速度、起止时间、最近保存的 CBZ 路径。
- 获取目录、登录、获取图片列表、下载图片、打包 CBZ、等待重试分别展示。未知总量时不显示虚假百分比，暂不预测剩余时间。
- 图片全下载后仍须完成 CBZ 保存和订阅记录写入，才计作完成一章。失败不推进完成记录。
- 失败、中断、停止的任务可重新检查并补下载：重新取得目录与图片地址，复用已经成功保存的图片。
- 正在运行的任务可请求完成当前章节后停止；排队任务可直接取消。
- 页面每两秒刷新状态，刷新失败时保留旧数据显示提示；订阅记录每五秒刷新。
- 任务记录存于现有 /data/download_tasks.json，保留最近 100 条已结束历史和全部活动任务；每个任务保留最近 50 条摘要事件。运行日志仍可在任务页查看。
- 容器重启后未结束任务标记为中断，由用户重试，不自动重新开始大批下载。

## 部署兼容

继续使用原端口和 /data、/downloads、/cbz 映射，无需增加环境变量或新挂载。保留 /data 即保留订阅、调度配置和任务历史。默认单进程 Web 服务运行；不要配置多个 Uvicorn worker 同时操作同一数据目录。

界面能呈现下载失败与进度，但不会解除 CopyManga 的 210 或网络限制。
